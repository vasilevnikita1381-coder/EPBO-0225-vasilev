# Практическая работа №1 — HTML и базовая CSS-разметка

## Описание
Многораздельная адаптируемая информационная страница факультета. Включает в себя навигацию, карточки направлений (загружаются из CSV), таблицу (загружается из CSV) и форму регистрации с валидацией.

## Технологии
- HTML5 (семантическая разметка)
- CSS3 (Flexbox, медиазапросы)
- JavaScript (Fetch API, работа с DOM, парсинг CSV и JSON)
- Git

## Как запустить локально
1. Клонировать репозиторий.
2. Открыть папку в VS Code.
3. Установить расширение Live Server.
4. Нажать правой кнопкой мыши на `index.html` и выбрать "Open with Live Server".

## Структура
- `index.html` — разметка страницы.
- `css/styles.css` — стили (в нашем случае просто `styles.css`).
- `script.js` — логика загрузки данных и заполнения страницы.
- `dataset/` — исходные данные (content.csv, navigation.json).
